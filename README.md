## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Install & Run

```bash
# Clone the repo
git clone https://github.com/sachit1751-art/portfolio.git

# Navigate into the project
cd portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```

The app will be live at `http://localhost:5173`.

### Build for Production

```bash
npm run build
npm run preview
```
